Class: Inscripcion

Inscripcion()

Entidad que representa la inscripción de un usuario en una materia. Mapea la tabla inscripciones. Es la tabla de unión entre Usuario y Materia. Se consulta desde EventosService y AvisosService para determinar qué usuarios deben recibir notificaciones al crearse eventos o avisos.
