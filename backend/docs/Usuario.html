Class: Usuario

Usuario()

Entidad que representa un usuario del sistema. Mapea la tabla usuarios. El acceso al sistema está controlado por el campo estado y el campo rol determina los permisos disponibles (Admin, Docente, Estudiante). La contraseña se almacena siempre hasheada con bcrypt.
