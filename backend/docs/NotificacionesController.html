Class: NotificacionesController

NotificacionesController()

Controlador de notificaciones internas. Todos los endpoints requieren autenticación. El ID del usuario se extrae del payload JWT (req.user.sub) en lugar de recibirlo como parámetro, garantizando que cada usuario solo acceda a sus propias notificaciones.
